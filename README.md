# Tasks for Today Management System

This is a CodeIgniter 4 task-management application.

## Features

- Shows tasks scheduled for today
- Shows all tasks ordered by date
- Shows one demo user's profile
- Includes an About page

## Installation

1. Download or clone the repository.
2. Run `composer install`.
3. Import `tasks_today_db.sql` into MySQL.
4. Rename `env` to `.env`.
5. Configure the database connection.
6. Run `php spark serve`.
7. Open `http://localhost:8080`.
